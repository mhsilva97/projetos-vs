# 🎮 Meus Primeiros Projetos em JavaScript

Bem-vindo ao meu repositório de aprendizado! Aqui estão meus projetos práticos desenvolvidos em JavaScript puro, criados para consolidar meus conhecimentos e retomar minha jornada na programação.

## 📌 Sobre

Este repositório contém projetos construídos do zero, focando na lógica de programação e na manipulação do DOM. Cada projeto foi desenvolvido passo a passo para garantir o entendimento real de cada conceito.

## 🚀 Projetos Incluídos

### 1. **Index.html** - Página Inicial
Primeira página HTML com interação básica em JavaScript.

### 2. **Desafio2.html** - Apresentação Interativa
Sistema que coleta nome e idade do usuário e exibe uma mensagem personalizada.
- **Conceitos:** Variáveis, `prompt()`, concatenação de strings.

### 3. **Desafio3.html** - Verificador de Idade
Aplicação que verifica se o usuário é maior ou menor de idade.
- **Conceitos:** Estruturas condicionais (`if/else`), operadores de comparação.

### 4. **Desafio4.html** - Classificador de Faixa Etária
Classifica o usuário em: Criança, Adolescente, Adulto ou Idoso.
- **Conceitos:** Múltiplas condições (`else if`), operadores lógicos.

### 5. **Adivinhe o Número** 
Jogo interativo onde o usuário deve adivinhar um número aleatório com contador de tentativas.
- **Conceitos:** `Math.random()`, loops (`while`), validação de entrada.

### 6. **Calculadora** 🧮
Calculadora interativa com tratamento de erros. Permite realizar operações matemáticas básicas e limpar a tela.
- **Funcionalidades:** Operações (+, -, *, /), botão de limpar (C), tratamento de expressões inválidas.
- **Conceitos:** `eval()`, tratamento de erros (`try/catch`), manipulação de eventos (`onclick`).

### 7. **Lista de Tarefas (To-Do List)** 
Aplicativo completo de gerenciamento de tarefas com persistência de dados. As tarefas não somem ao recarregar a página!
- **Funcionalidades:** Adicionar tarefas, marcar como concluída (riscar), excluir tarefas, contador de progresso.
- **Conceitos:** `localStorage` (persistência de dados), `createElement`, `appendChild`, `remove()`, Arrays e Objetos, `forEach`.
