# 🎮 Meus Primeiros Projetos em JavaScript

Bem-vindo ao meu repositório de aprendizado! Aqui estão meus primeiros projetos desenvolvidos em JavaScript puro, criados durante minha retomada na programação.

## 📌 Sobre

Este repositório contém projetos práticos desenvolvidos para consolidar meus conhecimentos em:
- HTML5 (estruturação de páginas)
- JavaScript (lógica de programação e interatividade)
- Manipulação do DOM
- Eventos e funções

## 🚀 Projetos Incluídos

### 1. **Index.html** - Página Inicial
Primeira página HTML com interação básica em JavaScript.

### 2. **Desafio2.html** - Apresentação Interativa
Sistema que coleta nome e idade do usuário e exibe uma mensagem personalizada.
- **Conceitos:** Variáveis, prompt, concatenação de strings

### 3. **Desafio3.html** - Verificador de Idade
Aplicação que verifica se o usuário é maior ou menor de idade.
- **Conceitos:** Estruturas condicionais (if/else), operadores de comparação

### 4. **Desafio4.html** - Classificador de Faixa Etária
Classifica o usuário em: Criança, Adolescente, Adulto ou Idoso.
- **Conceitos:** Múltiplas condições (else if), operadores lógicos

### 5. **Adivinhe o Número** 🎯
Jogo interativo onde o usuário deve adivinhar um número aleatório entre 1 e 10.
- **Funcionalidades:**
  - Geração de números aleatórios
  - Contador de tentativas
  - Feedback visual (maior/menor)
  - Loop while para repetição até acertar
- **Conceitos:** Math.random(), loops, validação de entrada
